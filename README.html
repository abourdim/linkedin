Features

Zero DependenciesVanilla HTML/CSS/JS. No Node, no npm, no build step.
3 LanguagesFrench, English, Arabic with full RTL support.
7 ThemesLight, Dark, Blue, High Contrast, Golden Age, Alhambra, Medina.
PIN AccessSHA-256 hashed PIN, 24h session, 3-attempt lockout.
Edit ModeModify any document in-browser. Auto-saved to localStorage.
DownloadsHTML, TXT, PDF, copy text, copy link.
Command PaletteCtrl+K for instant fuzzy search across all content.
Live JobsAdzuna API integration showing real job listings per country.

Tech Stack

  • Frontend: Vanilla HTML5 + CSS3 + ES6 JavaScript
  • Routing: Hash-based SPA (#/ch/cv, #/fr/plan, etc.)
  • Content: iframe-based loading (preserves document CSS)
  • Storage: localStorage (theme, language, PIN session, edits)
  • Security: SHA-256 via Web Crypto API
  • Server: Python 3 SimpleHTTPServer (dev only)
  • Hosting: GitHub Pages ready

Deploy to GitHub Pages

git remote add origin git@github.com:username/cv_updated.git
git push -u origin master

# Settings > Pages > Source: master branch, / (root)
# URL: https://username.github.io/cv_updated/jobs/

Change PIN

  1. Open the app in browser
  2. Open console (F12)
  3. Run: PIN.generateHash('your-new-pin')
  4. Copy the hash into jobs/js/pin.js line 10
