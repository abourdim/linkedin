Problème : Version B déborde sur 3 pages

Étape 7
⚠ Problème La Version B (avec Workshop-DIY en expérience complète) ajoutait trop de contenu en page 1. L'expérience Arkamys débordait seule sur une 3ème page.
✓ Solution — 6 ajustements CSS + contenu
  1. Réduction du padding sidebar header (22pt → 18pt)
  2. Réduction des initiales (60pt → 50pt)
  3. Réduction du padding sections sidebar (12pt → 9pt)
  4. Réduction du padding main (18pt → 14pt)
  5. Workshop-DIY : 5 bullets → 4 (fusion site web dans dernière ligne)
  6. Valeo : 3 bullets → 2 (condensé) / Arkamys : 4 bullets → 2
Exemples des ajustements CSS CSS
/* Avant */
.sidebar-header { padding: 22pt 14pt 18pt 14pt; }
.sidebar-section { padding: 12pt 14pt 8pt 14pt; }
.exp-block { margin-bottom: 10pt; }
.main { padding: 18pt 18pt 14pt 20pt; }

/* Après */
.sidebar-header { padding: 18pt 14pt 14pt 14pt; }
.sidebar-section { padding: 9pt 14pt 6pt 14pt; }
.exp-block { margin-bottom: 8pt; }
.main { padding: 14pt 16pt 10pt 18pt; }

Génération DOCX — Problème et solution

Étape 9
⚠ Problème 1 — LibreOffice HTML→DOCX échoue libreoffice --headless --convert-to docx cv_version_A.html
Erreur : "no export filter found, aborting"
Tentative LibreOffice (échouée) Bash
$ libreoffice --headless --convert-to docx cv_version_A.html
Error: no export filter for cv_version_A.docx found, aborting.
✓ Solution intermédiaire — Pandoc Pandoc peut convertir HTML→DOCX mais perd le design sidebar (DOCX ne supporte pas CSS flexbox).
Conversion Pandoc (contenu OK, design perdu) Bash
$ pandoc cv_version_A.html -o cv_abdelhak_bourdim_VERSION_A.docx
Version A OK
$ pandoc cv_version_B.html -o cv_abdelhak_bourdim_VERSION_B.docx
Version B OK
⚠ Problème 2 — DOCX Pandoc sans mise en forme Les fichiers DOCX générés par pandoc contiennent le texte brut sans couleurs, sans mise en forme professionnelle, sans bordures de section.
✓ Solution finale — Script python-docx dédié Création de generate_docx.py avec python-docx pour générer des DOCX formatés (couleurs, bordures, tableaux) directement depuis Python.
Script python-docx Bash
$ python3 generate_docx.py
