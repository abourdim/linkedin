	* INTERFACE CONTROL DOCUMENT (ICD)

	The present document defines the functional and physical characteristics of the interfaces between the Multi Mode Receiver (MMR) TLS 2060 and the external systems.

	This document acts a reference for the development of the hardware and software

	1.3 DOCUMENT OVERVIEW
	This document describes for the previously identified system/sub-System:
	*  the operational concepts (missions, operational and logistic support environments, architecture and operational scenarios selected),
	*  the system/sub-System design items (hardware, software, labour, internal interfaces between components),
	*  the processing resources,
	*  the design models and evaluation criteria,
	*  the traceability of the specification requirements to the system/sub-System components.
	This document acts a reference for the development of the hardware and software of the previously identified system/sub-System.
	It defines the allocation of performance capabilities and functionalities between the various components of the system/sub-System.
	It provides complementary system requirements to the SSS and ICD documents.
	These requirements may establish a link with either SSS or ICD requirements and therefore details or interprets these requirements.
	They also act as design considerations derived requirements and, consequently, no link is provided with ICD / SSS requirements.

Clean Code :
Un code compréhensible de façon intuitive et facile à modifier.
	* Le processus d'exécution de l'ensemble de l'application est logique et structuré de façon simple.
	* Le rapport entre les différentes parties du code est transparent.
	* La tâche ou le rôle de chaque classe, fonction, méthode et variable est immédiatement compréhensible.

Un code aussi simple que possible : KISS
