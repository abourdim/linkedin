1. Vue d'ensemble

Ce système génère 2 versions du CV en 2 formats (PDF et DOCX), soit 4 fichiers au total :

Version A — Sidebar discrète

Workshop-DIY mentionné dans le profil + section dédiée dans la sidebar (page 2). Idéal pour missions ESN / Freelance embarqué classique.

ESN / Freelance

Version B — Expérience complète

Workshop-DIY en première position des expériences avec bloc highlight. Idéal pour CDI client final, rôles lead/chef de projet.

CDI / Lead technique

Format PDF

Design moderne avec sidebar bleu marine, initiales, dots de langues, tags de normes. Généré depuis HTML/CSS via WeasyPrint.

HTML → PDF

Format DOCX

Format Word classique, facilement éditable dans LibreOffice/Word. Généré via python-docx. Pas de sidebar (limitation du format).

python-docx

$ cd ~/Downloads/02_cv/

6. Modifier le contenu

Pour les PDF (modifier le HTML)

Ouvrir cv_version_A.html ou cv_version_B.html dans un éditeur de texte.

Exemple : ajouter une nouvelle expérience HTML
<!-- Copier un bloc exp-block existant et modifier -->
<div class="exp-block">
  <div class="exp-header">
    <span class="exp-company">Nouvelle Entreprise &mdash; Ville</span>
    <span class="exp-dates">Jan. 2026 &ndash; En cours</span>
  </div>
  <div class="exp-project">Nom du projet</div>
  <div class="exp-intervention">Description courte</div>
  <ul class="exp-bullets">
    <li>Première réalisation</li>
    <li>Deuxième réalisation</li>
  </ul>
  <div class="exp-env"><strong>Env :</strong> C, Python, etc.</div>
</div>

Pour les DOCX (modifier le Python)

Ouvrir generate_docx.py et modifier les fonctions de contenu.

Exemple : ajouter une expérience dans le DOCX Python
# Dans la fonction add_common_experiences() ou generate_version_b()
add_company_header(doc, "Nouvelle Entreprise", "Ville", "Jan. 2026 – En cours")
add_project_line(doc, "Nom du projet", "Description courte")
add_bullet(doc, "Première réalisation")
add_bullet(doc, "Deuxième réalisation")
add_env_line(doc, "C, Python, etc.")

Modifier les informations de contact

Dans le HTML (PDF) HTML
<!-- Chercher la section class="sidebar-section" avec Contact -->
<span>nouveau.email@example.com</span>
<span>+33 X XX XX XX XX</span>
Dans le Python (DOCX) Python
# Chercher dans la fonction add_header()
run = p.add_run("nouveau.email@example.com  |  +33 X XX XX XX XX  |  Ville")

Ajouter une compétence technique

Dans le HTML (sidebar) HTML
<!-- Trouver le skill-category correspondant -->
<div class="skill-value">C, C++, Python, Bash, Rust, Assembleur</div>
Dans le Python (table) Python
# Chercher skills_data dans add_skills_table()
("Langages", "C, C++, Python, Bash, Rust, Assembleur, Perl, Awk"),

7. Modifier le style CSS (PDF)

Tout le design du PDF est dans le bloc <style> en haut des fichiers HTML.

Changer la couleur principale

Remplacer le bleu par du vert par exemple CSS
/* Chercher/remplacer dans le <style> */
/* Bleu actuel: */   #1a2a4a  →  #1a4a2a  /* sidebar background */
/* Bleu accent: */  #2e6db4  →  #2eb46d  /* accents, bordures */
/* Bleu clair: */   #4a8fd4  →  #4ad48f  /* titres sidebar */

Changer la police

CSS
body {
  font-family: 'Roboto', 'Helvetica Neue', Arial, sans-serif;
}

Ajuster les marges de page

CSS
@page {
  size: A4;
  margin: 0;  /* 0 car le layout est en pleine page */
}

/* Ajuster le padding du contenu principal */
.main {
  padding: 14pt 16pt 10pt 18pt; /* top right bottom left */
}

Ajuster la taille de la sidebar

CSS
.sidebar {
  width: 68mm;  /* augmenter pour plus de place, diminuer pour plus de contenu principal */
}
Attention au nombre de pages Après modification du CSS, toujours vérifier que le CV tient sur 2 pages. Ajuster les margin-bottom, padding et font-size si nécessaire.

8. Modifier le style DOCX

Le style DOCX est défini par les constantes et paramètres dans generate_docx.py.

Couleurs (en haut du script) Python
DARK_BLUE   = RGBColor(0x1A, 0x3C, 0x6E)  # Titres de section
MEDIUM_BLUE = RGBColor(0x2B, 0x57, 0x97)  # Noms d'entreprise
BLACK       = RGBColor(0x2D, 0x2D, 0x2D)  # Texte courant
GRAY        = RGBColor(0x55, 0x55, 0x55)  # Dates, sous-titres
Marges et police (dans setup_doc) Python
section.top_margin = Cm(1.5)
section.left_margin = Cm(1.8)
style.font.name = 'Calibri'
style.font.size = Pt(9.5)

10. Dépannage

WeasyPrint ne s'installe pas

Terminal
# Installer les dépendances système (Ubuntu/Debian)
$ sudo apt install libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf2.0-0 libffi-dev shared-mime-info

# Puis réinstaller
$ pip install --force-reinstall weasyprint

Le PDF fait 3 pages au lieu de 2

Réduire les espaces dans le CSS :

CSS
/* Réduire l'espace entre les blocs d'expérience */
.exp-block { margin-bottom: 6pt; }  /* au lieu de 8pt */

/* Réduire la taille des bullets */
.exp-bullets li { font-size: 7.5pt; }  /* au lieu de 7.8pt */

/* Réduire le padding de la sidebar */
.sidebar-section { padding: 8pt 14pt 5pt 14pt; }

Erreur "No module named 'docx'"

Terminal
$ pip install python-docx   # ⚠️ pas "docx" mais "python-docx"

Les polices sont différentes sur un autre PC

WeasyPrint utilise les polices système. Si Segoe UI n'est pas installée, il fallback sur Helvetica Neue puis Arial. Pour forcer une police :

Terminal
# Installer les polices Microsoft (optionnel)
$ sudo apt install fonts-liberation ttf-mscorefonts-installer

Regénérer tout en une commande

Terminal
$ cd ~/Downloads/02_cv/ && python3 generate_pdf.py && python3 generate_docx.py
