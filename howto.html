1. Quick Start

# Option A: use the launcher script
chmod +x start_here.sh
./start_here.sh

# Option B: use Python directly
python3 serve.py

# Option C: custom port
python3 serve.py 3000

The browser opens automatically at http://localhost:8000/jobs/.

Default PIN: 123456

2. Architecture

Single Page Application (SPA)
  • Zero dependencies — pure vanilla HTML, CSS, JavaScript
  • No build step — no Node.js, no npm, no webpack
  • Hash-based routing — #/ch/cv, #/fr/plan, #/lu/pitch, etc.
  • iframe content loading — each document preserves its own CSS styling
  • localStorage persistence — theme, language, PIN session, edited documents
jobs/
  index.html          Main SPA entry point
  css/
    spa.css           Layout, sidebar, content area
    themes.css        7 visual themes (CSS custom properties)
  js/
    app.js            Core SPA + content map + routing
    pin.js            6-digit PIN with SHA-256 hashing
    i18n.js           FR/EN/AR language switcher + RTL
    themes.js         7-theme switcher
    editor.js         Edit mode (contenteditable + localStorage)
    downloads.js      Download HTML/TXT/PDF + copy text/link
    jobs.js           Live job listings via Adzuna API

4. Languages & RTL

Three Languages
  • FR French — default language
  • EN English — full translation
  • AR Arabic — full RTL support (dir="rtl", direction: rtl, text-align: right)

Arabic files use .latin CSS class (direction: ltr; unicode-bidi: isolate) to keep company names and technical terms in Latin script inline.

Language switcher in the top-right of the sidebar. Persists in localStorage.

6. PIN Access

Security
  • Default PIN: 123456
  • PIN is hashed with SHA-256 via Web Crypto API — never stored in clear text
  • Session persists for 24 hours in localStorage
  • 3 failed attempts = 30-second lockout

Change the PIN

Open the browser console and run:

PIN.generateHash('your-new-pin')

Copy the hash and replace HASH in jobs/js/pin.js line 10.

7. Features

Edit Mode

Click the Edit button on any document to enable contenteditable. Changes are saved to localStorage and persist across sessions. Click Reset to restore the original.

Downloads

Each document can be downloaded in multiple formats:

  • HTML — original formatted file
  • TXT — plain text version (when available)
  • PDF — generated via browser print (Ctrl+P)
  • Copy Text — copies content to clipboard
  • Copy Link — copies direct URL to document

Command Palette

Press Ctrl+K to open the command palette. Search for any country, section, or action. Fuzzy matching supported.

10. Live Job Listings (Adzuna API)

Configuration

The "Jobs" section in each country fetches live listings from the Adzuna API.

To configure, edit the API credentials in jobs/js/jobs.js:

APP_ID: 'your-app-id',
APP_KEY: 'your-app-key'

Free tier: 250 requests/month. Regions supported: gb, us, fr, de, at, ch, etc.

12. How to Customize

Add a new country

  1. Create content files (CV, plan, pitch, letter, prompts, queries) in FR/EN/AR
  2. Add the country to the CONTENT map in jobs/js/app.js
  3. Add country label translations in jobs/js/i18n.js

Change the PIN

  1. Open browser console on the app
  2. Run PIN.generateHash('newpin')
  3. Copy the hash into jobs/js/pin.js line 10

Add a new theme

  1. Add a new [data-theme="mytheme"] block in jobs/css/themes.css
  2. Register it in the THEMES array in jobs/js/themes.js

Edit document content

Either edit the source HTML files directly, or use the built-in Edit Mode in the app (changes saved to localStorage).
