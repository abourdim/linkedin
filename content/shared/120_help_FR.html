Comment utiliser le site, les documents, et les outils disponibles

1. Acceder au portfolio

1 Ouvrez abourdim.github.io/linkedin/jobs/
2 Entrez le code PIN : 123456 (clavier ou clic)
3 Le portfolio s'ouvre sur le CV Format Suisse par defaut
Astuce : Le PIN est memorise 24h — pas besoin de le retaper a chaque visite.

4. Fonctionnalites avancees

Raccourcis clavier

RaccourciAction
Ctrl + KOuvrir la palette de commandes (recherche rapide)
EchapFermer la palette / sidebar mobile

Themes

7 themes disponibles — cliquez sur les ronds colores en bas de la sidebar :

Light, Dark, Blue, Contraste, Golden Age, Alhambra, Medina

Mode edition

Cliquez sur le bouton crayon dans la barre d'outils pour activer le mode edition. Modifiez directement le contenu — vos modifications sont sauvegardees localement (localStorage).

Flash Cards

Dans "Prepa Entretien > Flash Cards" — 30 cartes interactives a cliquer pour reviser :

  • TECH (bleu) — 10 cartes competences techniques
  • Q&A (orange) — 10 cartes questions d'entretien
  • VOCAB (vert) — 10 cartes vocabulaire FR/EN

Utilisez les filtres en haut pour cibler une categorie.

Copier les prompts et requetes

Dans les pages "Prompts IA" et "Requetes LinkedIn" :

  • Prompts : cliquez sur le bouton Copier en haut a droite de chaque prompt
  • Requetes : cliquez directement sur la requete (elle devient verte = copiee)

5. Dossier Delivery

Le dossier delivery/ contient tous les PDFs prets a envoyer, organises par pays et langue :

delivery/
  01_ch/   01_FR/  02_EN/  03_AR/
  02_fr/   01_FR/  02_EN/  03_AR/
  03_lu/   01_FR/  02_EN/  03_AR/
  04_gulf/ 01_FR/  02_EN/  03_AR/
  05_shared/ (generiques)

Les fichiers sont numerotes pour un reperage facile (00 = CV 1 page, 01 = CV, 02 = Lettre, etc.)

6. Google Analytics

Le site est connecte a Google Analytics. Pour voir les statistiques :

1 Allez sur analytics.google.com
2 Selectionnez la propriete "Portfolio Abdelhak"
3 Temps reel : voir qui est en ligne maintenant
4 Rapports > Engagement > Pages : pages les plus vues
5 Rapports > Acquisition : d'ou viennent les visiteurs
Astuce recruteur : Quand vous envoyez votre lien portfolio a un recruteur, verifiez le rapport "Temps reel" pour voir s'il l'a ouvert.

7. Hors ligne (PWA)

Le site fonctionne hors connexion grace au service worker. Apres une premiere visite, les pages sont mises en cache automatiquement.
