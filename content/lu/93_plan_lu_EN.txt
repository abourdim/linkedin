PART 2 — CROSS-BORDER WORKER STATUS
============================================================

Recommended option: cross-border worker from Lorraine/Metz

You currently live in the Paris region. Three possible strategies:

Option A — Relocate near Luxembourg (cross-border)
- Settle in Lorraine (Metz, Thionville, Longwy) or Belgium
- Daily commute: Metz-Luxembourg ~60 min, Thionville ~30 min
- No work permit required for EU/French citizens
- Taxation: Luxembourg tax (favorable rates), bilateral agreement
- Advantage: Luxembourg salary + French cost of living

Option B — Settle directly in Luxembourg
- High rents (EUR 1,500 - 2,500 for an apartment)
- But no daily commute constraint
- Better local integration

Option C — Start remotely then relocate
- Some employers accept partial remote work
- Start the job, then relocate after 2-3 months

Procedures (EU citizen)
1. No work permit required for French citizens
2. As cross-border worker: no administrative procedures on Luxembourg side
3. Automatic affiliation to Luxembourg social security
4. If resident: arrival declaration within 3 days, residence card within 3 months
