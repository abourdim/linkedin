Prompt 1 — Generer une lettre de motivation FR

Utilisez ce prompt en remplacant les champs [ENTRE CROCHETS] :

Tu es un expert en redaction de lettres de motivation pour le marche francais. Redige une lettre de motivation en francais pour le poste suivant : Poste : [TITRE DU POSTE — ex: Ingenieur Logiciel Embarque Senior] Entreprise : [NOM DE L'ENTREPRISE — ex: Safran Electronics & Defense] Lieu : [VILLE — ex: Massy, Ile-de-France] Source de l'offre : [LinkedIn / APEC / Indeed / candidature spontanee] Voici mon profil : - Abdelhak Bourdim, ingenieur logiciel embarque senior, 20+ ans d'experience - Nationalite francaise, disponible en CDI, mobilite France entiere - Competences cles : C/C++, RTOS (FreeRTOS, VxWorks), Linux embarque, ARM Cortex, STM32 - Protocols : CAN, CANOpen, BLE, USB, TCP/IP, SPI, I2C - Normes : DO-178 (aeronautique), IEC 62304 (medical), MISRA C, ISO 15118 (V2G) - Secteurs : aeronautique (Safran, Thales), medical (GE Healthcare, Sorin), automobile (Valeo), cybersecurite IoT (Enedis/Linky), recharge EV/V2G (E2-CAD) - Fondateur de Workshop-DIY (association robotique pour jeunes) - Langues : francais (natif), anglais (professionnel), arabe (natif) Consignes pour la lettre : 1. Format francais : professionnel, structure, engageant 2. Maximum 1 page (300-400 mots) 3. Mettre en avant les competences qui correspondent specifiquement a l'offre 4. Expliquer brievement pourquoi cette entreprise en particulier 5. Mentionner la disponibilite et la mobilite 6. Terminer par une formule de politesse appropriee 7. Ton : professionnel mais humain, pas de cliches Si c'est une candidature spontanee, adapter le ton en consequence.

Prompt 11 — Negociation salariale FR

Tu es un expert en negociation salariale pour le marche francais de l'embarque. Poste propose : [TITRE] Entreprise : [NOM] Lieu : [VILLE / REGION — ex: Massy, Ile-de-France] Type de contrat : CDI Offre salariale : [MONTANT — ex: 65 000 EUR/an] Convention collective : [Syntec / Metallurgie / autre] Mon profil : - 20+ ans d'experience, ingenieur logiciel embarque senior - Competences rares : DO-178, IEC 62304, cybersecurite embarquee, V2G/ISO 15118 - Trilinguisme FR/EN/AR Aide-moi a : 1. Evaluer l'offre : est-ce dans la fourchette du marche ? (comparer IDF vs province) 2. Points de negociation : quels elements negocier au-dela du salaire (teletravail, RTT, formation, tickets restaurant, interessement, PEE, vehicule) 3. Script de negociation : redige 3 phrases cles pour negocier de maniere professionnelle 4. Calcul net : estimation du salaire net a partir du brut (charges sociales ~22-25%) 5. Elements a eviter : erreurs courantes en negociation en France

Comment utiliser ces prompts

1 Copiez le prompt qui vous interesse
2 Remplacez les champs [ENTRE CROCHETS] avec vos informations
3 Collez dans ChatGPT, Claude, ou tout autre IA
4 Adaptez la reponse a votre style personnel
IMPORTANT : Ne jamais envoyer un texte genere par IA sans le relire et le personnaliser. L'IA est un outil d'aide, pas un remplacement de votre jugement.

Ordre recommande pour une candidature

1 Prompt 9 — Analyser l'offre → comprendre ce que l'entreprise cherche

2 Prompt 1 ou 2 — Lettre de motivation → candidater

3 Prompt 3 ou 4 — Message LinkedIn → networking en parallele

4 Prompt 7 ou 8 — Preparation entretien → avant chaque entretien

5 Prompt 10 — Suivi → apres chaque entretien

6 Prompt 11 — Negociation → quand vous recevez une offre
